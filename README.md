# 🧠 Machine Learning Projects

This repository contains a collection of end-to-end machine learning projects, covering data preprocessing, exploratory data analysis (EDA), model building, visualization, and evaluation.  
Each project demonstrates different ML techniques and problem-solving workflows.

---

## 📌 Projects Overview

### 1️⃣ Regression – **Black Friday Sales Prediction**
- **Goal:** Predict purchase amounts from customer and product data.
- **Tasks:** Data cleaning, feature preprocessing, EDA, regression modeling, performance evaluation.
- **Dataset:** [Black Friday Sales Dataset](https://www.kaggle.com/datasets/rishikeshkonapure/black-friday-sales-eda)

---

### 2️⃣ Clustering – **Book Genre Analysis**
- **Goal:** Cluster books based on their summaries using NLP techniques.
- **Tasks:** Text preprocessing (tokenization, TF-IDF), clustering (e.g., K-Means), keyword extraction, WordCloud visualization.
- **Validation:** Compared clusters with actual genres for interpretability.

---

### 3️⃣ Deep Learning – **Fashion-MNIST Classification**
- **Goal:** Classify 70,000 fashion images into 10 classes.
- **Tasks:** ANN/MLP model design (Flatten → Dense layers + Dropout → Softmax), training, accuracy evaluation, confusion matrix & learning curve visualization.
- **Dataset:** [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist)

---

### 4️⃣ Dimensionality Reduction – **PCA + Audio Classification**
- **Goal:** Classify spoken digits using spectrogram features with and without PCA.
- **Tasks:** Convert audio → spectrograms, apply PCA for dimensionality reduction, train classifiers, compare runtime & accuracy before/after PCA.
- **Dataset:** [Free Spoken Digit Dataset](https://www.kaggle.com/datasets/alanchn31/free-spoken-digits)

---

### 5️⃣ Time Series Forecasting – **CO₂ Emissions**
- **Goal:** Forecast CO₂ emissions for the next 36 months.
- **Tasks:** Time series decomposition, train/test split, ARIMA/seasonal forecasting, result visualization with trend lines.

---

## 🛠 Tech Stack

- **Languages & Libraries:** Python (pandas, NumPy, scikit-learn, matplotlib, seaborn)
- **Deep Learning:** TensorFlow / PyTorch (ANN/MLP)
- **NLP:** NLTK / spaCy, TF-IDF, clustering algorithms
- **Time Series:** statsmodels, ARIMA/seasonal analysis
- **Visualization:** Matplotlib, Seaborn, WordCloud

---

## 📊 Key Skills Demonstrated
- Data preprocessing & feature engineering  
- Regression, clustering, and dimensionality reduction  
- Neural network design (ANN/MLP)  
- Time series forecasting & model evaluation  
- Data visualization & reporting
